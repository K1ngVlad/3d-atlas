## Исправить после шага 4 (экран атласа)
- [x] **`AtlasStore` перехватывает чужие маршруты**: подписка на `NavigationEnd` живёт в root-сервисе, `parsePath('/quiz')` → `[]` → редирект на `/atlas/animal-cell`. После первого входа в атлас нельзя открыть «Тесты», «Загрузку», «Аналитику», `/sandbox`. Реагировать только на URL `/atlas…`; редирект `/atlas` → корень делать маршрутом, а не в сторе
- [x] Возврат в атлас из другого раздела: `bootstrapped` уже `true`, а `syncWithUrl` из `NavigationEnd` может вызвать `viewer.load` до `attach` (ошибка «viewer not attached» глотается) → пустая сцена. Загружать текущий уровень при `attach`, а не флагом `bootstrapped`
- [x] Двойной старт: при первом входе `syncWithUrl` вызывается и из `NavigationEnd`, и из `bootstrap()`. `syncWithUrl` должен быть последовательным (последний вызов отменяет предыдущий)
- [x] Гонка загрузок в ядре: `load()` не отменяет предыдущую активацию — при быстрых переходах может победить устаревший манифест (сейчас маскируется общим кэшем модели, проявится с настоящими детальными моделями). Токен/AbortController в `load` ядра
- [ ] Переход через несколько уровней (крошка «Клетка» с глубины 3, ссылка) строит стек заново с `state: null` — камера и выбор верхнего уровня теряются. Брать `state` из существующего стека по совпадающему префиксу
- [ ] `restore` подменяет `options` в ядре, а `AtlasStore.options` — нет: тулбар показывает не то состояние. Либо не хранить `options` во `ViewState` уровня, либо синхронизировать сигнал
- [ ] Неиспользуемый `DestroyRef` в `AtlasStore`
