## Сноски: доработки (отложено)
Сноски рабочие; удобство доведём позже, после расслоения и детальных моделей.
- [ ] Подтверждение окклюзии считает **кадры**, а не проверки: `occludedStreak` растёт в `place()` на каждом кадре, а `candidateOccluded` обновляется раз в 150 мс — «две проверки подряд» фактически = два кадра. Считать только при `refreshOcclusion`
- [ ] Сглаживание подписей живёт внутри `computed` и двигается только на отрисованных кадрах: когда камера останавливается, подписи замирают не дойдя до цели, при следующем кадре (`dt` до 500 мс) прыгают. Отдельный rAF-цикл раскладки, пока подписи не пришли к цели (или запрос кадра у ядра)
- [ ] Длина выноски по умолчанию — 256 px (`leaderLength`), в спецификации ~64 px: подобрать на реальных сценах, возможно — колонки подписей за силуэтом модели
- [ ] Кандидат на обратной стороне части не считается закрытым (собственные меши исключены из окклюзии) — точка может оказаться «за» частью
- [ ] Сторона подписи — относительно среднего X якорей, а не экранного центра модели
