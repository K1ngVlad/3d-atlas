## Решение по ЭПР

Шероховатый и гладкий ЭПР — части одной непрерывной мембранной системы. Вместо двух отдельных моделей — **одна детальная модель ЭПР с двумя частями** (`rough-er`, `smooth-er`). Найденную модель всего ЭПР разделить в Blender (Separate → Selection) на два именованных объекта (если лицензия допускает изменения: не ND).

Клик по шероховатому или гладкому ЭПР в клетке открывает модель всего ЭПР с подсветкой и подлётом к выбранной части (`detail: { id, focus }`).

## Научные источники (на будущее)

- **OpenOrganelle (Janelia)** — реконструкции органоидов реальных клеток по FIB-SEM (HeLa, Jurkat, макрофаг), 35 классов органоидов, CC BY 4.0. Данные, а не готовые модели: нужен конвейер «сегментация → меш → glb». Идея: режим «как на самом деле» рядом со схемой.
- **Allen Cell Explorer** — 3D-изображения человеческих стволовых клеток, образовательные инструменты. Условия использования проверить.
- **cellPACK / Mesoscope (Scripps)** — мезомасштабные модели, молекулярный уровень.

## Атрибуция

Для CC BY: автор, ссылка на оригинал, лицензия, отметка об изменении. Для ND-моделей — `modified: false` и `technical` с описанием сжатия; адаптации (разрезание, перекраска, удаление объектов) запрещены. Данные хранятся в `source` манифеста и выводятся внизу правой панели. Позже — страница «Источники и лицензии».
