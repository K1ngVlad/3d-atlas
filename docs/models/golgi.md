## Особенности исходника

- Всего два меша: **все цистерны одним** (`GA`, 45 632 треугольника) и **все пузырьки одним** (`vesicles`, 7 040). Выбирать их по отдельности нельзя — нужно разделение.
- Геометрия чистая: связные куски однозначны — 8 цистерн (крайние меньше, средние крупнее) и 22 пузырька по 320 треугольников. Дубликатов и лишних объектов нет.
- Цистерны стоят рядом вдоль оси X модели (ось стопки). Пузырьки — у двух краёв стопки: 7 мелких круглых у одного, 15 более крупных, частью вытянутых, — у другого.
- Материалы непрозрачные, текстур нет — проблем сортировки прозрачности (как у митохондрии) нет.
- Корень `Sketchfab_model` повёрнут на −90° по X. Для ядра это проверка: смещения расслоения переводятся в координаты родителя обратной матрицей, а не нормальной (`roadmap.md`, «Исправить после этапа 5»).

## Цис- и транс-сторона — предположение

Автор не подписал стороны. Принято: сторона **15 крупных и вытянутых** пузырьков — **транс** (секреторные пузырьки обычно крупнее), сторона **7 мелких** — **цис** (транспортные пузырьки из ЭПР). Это вывод по форме, а не данные автора — **уточнить у медуниверситета**. Если наоборот — `CIS_SIDE = 1` в скрипте, пересобрать модель; манифест не меняется.

## Что делает скрипт

1. Проверяет исходник: 52 672 треугольника.
2. Делит оба меша на связные куски (сварка вершин по позиции): 8 цистерн, 22 пузырька — иначе ошибка.
3. Упорядочивает цистерны вдоль оси стопки от цис-края: `Cisterna.1…8`; группы: 1–2 — цис, 3–6 — срединные, 7–8 — транс.
4. Делит пузырьки по стороне стопки (проверка: ни один не лежит у середины стопки, иначе сторона неоднозначна): `TransportVesicle.01…07`, `SecretoryVesicle.01…15`.
5. Собирает иерархию; группы `Cisternae` и `Vesicles` получают матрицы исходных узлов `GA` и `vesicles`, положения не меняются.
6. Проверяет баланс треугольников, все ожидаемые имена, отсутствие исходных узлов; `dedup` + `prune` + `meshopt` (без `instance`).

```
Sketchfab_model → Collada visual scene group
├─ Cisternae
│  ├─ CisCisternae      Cisterna.1, Cisterna.2
│  ├─ MedialCisternae   Cisterna.3 … Cisterna.6
│  └─ TransCisternae    Cisterna.7, Cisterna.8
└─ Vesicles
   ├─ TransportVesicles  TransportVesicle.01 … .07
   └─ SecretoryVesicles  SecretoryVesicle.01 … .15
```

Проверка результата: рендер исходника и подготовленной модели с шести ракурсов — различается 0,02–0,06 % пикселей (сглаживание краёв), видимых отличий нет.

## Части в манифесте

| Часть | Узел | `select` | Расслоение |
|---|---|---|---|
| `cis-cisternae` | `CisCisternae` | целиком | стопка в сторону −X (от срединных) |
| `medial-cisternae` | `MedialCisternae` | целиком | на месте |
| `trans-cisternae` | `TransCisternae` | целиком | стопка в сторону +X |
| `transport-vesicles` | `TransportVesicles` | по одному | вместе с цис-цистернами |
| `secretory-vesicles` | `SecretoryVesicles` | по одному | вместе с транс-цистернами |

Цистерны выбираются группами (так объясняют в учебниках: цис → срединные → транс). Если понадобится выбирать каждую цистерну — одна часть `{"nodes": ["Cisternae"]}` с `select: "each"` не подойдёт (у `Cisternae` дети — группы), нужен селектор `{"match": "^Cisterna\\.\\d+$"}`.
