## Десктоп: раскладка

- **Шапка** (56 px): логотип «Атлас», разделы.
- **Холст** с моделью на всю оставшуюся ширину.
- **Поверх холста:**
  - слева сверху — кнопка «Назад» (если уровень не корневой) и хлебные крошки: «Клетка › Митохондрия»;
  - снизу по центру — панель вида: «Сноски», «Расслоение», «Подсветка», «Изоляция», «Сбросить вид»;
  - слева снизу — подсказка по управлению.
- **Правая панель** (340–380 px): только информация, без настроек.
  - тип и название текущей сущности, описание;
  - кнопка «Подробнее», если у выбранного элемента есть детальная модель;
  - список «Состав» / «Строение»: части текущего уровня, клик = клик по мешу; элементы с детальной моделью помечены «детально»;
  - внизу — источник модели: автор, площадка, лицензия, отметка «изменена».
  - кнопка скрытия панели. В скрытом состоянии в правом верхнем углу холста появляется кнопка «Описание» на том же месте. Состояние панели запоминается на сеанс.

## Взаимодействия

### Наведение
- Подсвечивает зону интереса (если включена «Подсветка»).
- Наведение на сноску подсвечивает меш, и наоборот.

### Клик
- **Одиночный клик** по мешу или сноске — выбор: камера плавно подлетает к элементу, он выделяется, остальные приглушаются; в панели — описание и «Подробнее».
- **Двойной клик или повторный клик по выбранному** — сразу переход к детальной модели (если она есть).
- **Клик по пустому месту или Esc** — снять выбор, в панели снова описание всей модели.
- В фоне после выбора начинается предзагрузка детальной модели.

### Какой элемент считается кликнутым
- Составной органоид, у которого есть детальная модель, на уровне родителя выделяется **целиком**: клик по ядрышку в модели клетки выделяет всё ядро. Его компоненты выбираются только после перехода на детальный уровень.
- У каждой части в манифесте режим `pick`: `select` (выбирается), `pass` (клик проходит насквозь — полупрозрачные наполнители вроде нуклеоплазмы), `block` (клик останавливается, ничего не выбрано).
- Алгоритм и правила разметки — `docs/05-manifest.md`, «Выбор по клику».

### Повторяющиеся органоиды
- Одинаковые органоиды в разных местах (митохондрии) выбираются **по одному**: камера подлетает к выбранному, он выделяется.
- Остальные экземпляры той же части получают слабую подсветку, чтобы было видно, что таких несколько.
- В панели: название, «1 из 3» и кнопки ‹ › — переход к следующему экземпляру с подлётом камеры. Описание и «Подробнее» общие.
- Сноска — только у одного экземпляра.

### Сноски
- Над каждой части с якорем. Клик по сноске = клик по части.
- Значок лупы на сноске: у части есть детальная модель.
- Сноски, чья точка привязки скрыта за геометрией, приглушаются.
- Переключатель «Сноски» скрывает все.

### Расслоение
- Части выезжают из модели и встают в столбец рядом с ней. Порядок и направление берутся из манифеста.
- Оболочка (части с `explode.stay`) остаётся на месте.
- Клик по части в столбце работает как обычно.
- Выключение плавно возвращает части на исходные позиции.

### Изоляция
- Показать только выбранную часть, остальное скрыть или сделать полупрозрачным.

### Переход к детальной модели
- Полностью клиентский переход по маршруту, например `/atlas/cell/mitochondrion`.
- Текущее состояние уровня (камера, режимы, выбор) сохраняется в стек.
- Крошки и панель сразу переключаются на новый уровень (описание берётся из контента, оно быстрое).
- Старая модель приглушается и остаётся на месте, поверх — карточка загрузки: прогресс в %, «X из Y МБ», «Отменить». Панель вида неактивна, в списке «Строение» скелетоны.
- После загрузки корневая модель плавно исчезает, детальная проявляется.
- Ошибка загрузки: сообщение, «Повторить», «Назад».
- Если модель уже предзагружена, экран загрузки не показывается.

### Возврат
- «Назад», клик по крошке или кнопка «назад» браузера.
- Детальная модель исчезает, родительская появляется **в сохранённом состоянии**: та же камера, режим расслоения, выбранный элемент.

## Мобильная версия (390 px)

- **Шапка:** логотип и бургер. Меню выезжает сверху поверх затемнённого холста, разделы с иконками.
- **Крошки** слева сверху, компактные.
- **Панель вида** — вертикальный столбец иконок справа сверху: сноски, расслоение, изоляция, сброс. «Подсветки» нет — нет наведения.
- **Нижняя шторка** вместо правой панели, три точки остановки:
  1. свёрнута — только тип и название;
  2. наполовину — описание, крупная «Подробнее», крестик снятия выбора;
  3. полностью — список состава / строения.
  Доводка к точке по скорости жеста. Перетаскивание за ручку всегда, за содержимое — только если список прокручен до верха. Ручка — кнопка (переключает положения), Esc сворачивает.
- **Камера учитывает шторку:** выбранный объект центрируется в видимой над шторкой области (`setViewportInsets`). Высота холста при движении шторки не меняется.
- **Сноски на детальных моделях** — пронумерованные маркеры, расшифровка в шторке. Режим сносок адаптивный: текст на десктопе, номера на узком экране. Манифест для этого не меняется.
- Тап — выбор, двойной тап или «Подробнее» — переход.
